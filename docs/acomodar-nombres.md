# Acomodar nombres

Cuando el usuario diga **acomodar nombres**, revisar los nombres de la categoría indicada. Si el contexto es Distribuidora, usar **COMPRAS PARAGUAY**.

1. Leer los nombres actuales y tomar como patrón los productos similares ya corregidos por el usuario.
2. Corregir caracteres dañados, espacios y tildes. Traducir términos descriptivos al español de Argentina; conservar nombres comerciales, marca, modelo y códigos.
3. Usar nombres breves: **tipo de producto + marca + modelo · característica distintiva · capacidad o tamaño · color**. Omitir segmentos que no correspondan.
4. Conservar diferencias entre variantes: capacidad, tamaño, conectividad, generación, kit, color y accesorios incluidos. No inventar prestaciones ni corregir modelos por suposición.
5. Respetar los nombres ya claros. Unificar mayúsculas y separadores dentro de cada familia siguiendo sus ejemplos existentes.
6. Traducir colores solo cuando sean inequívocos. Conservar el nombre comercial si su equivalencia es dudosa.
7. Guardar únicamente el nombre, sin cambiar precios, impuestos, proveedor, URL, fotos ni nombres históricos en ventas. Actualizar también la ficha pública correspondiente.
8. Preparar una relación antes/después, conservar respaldo y verificar que el nombre no haya cambiado desde la revisión antes de escribir. Informar cuántos se revisaron y cuántos se corrigieron.

Ejemplos: `FONE DE OUVIDO` → `Auriculares`; `SEM FIO` → `inalámbrico`; `PRATA` → `plateado`; `GARRAFA TÉRMICA` para mate → `Termo`.
