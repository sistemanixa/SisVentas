# Cotización sin comparación de nombre

Se eliminó la comparación de palabras, marcas, modelos y especificaciones entre el nombre interno y el título del proveedor. La ficha y el masivo comparten el cotizador modificado. No se modifican nombres ni datos comerciales del catálogo.

Se mantienen: URL y dominio autorizado, presencia de producto, identificadores oficiales cuando falta título en Mercado Libre, precio válido, moneda y revisión de variaciones excepcionales. Se eliminó el código de normalización usado únicamente por la comparación de nombres.

Validación: 33 pruebas de cotización y lotes aprobadas; 10 pruebas dirigidas de interfaz, protección de consulta y conservación de precios aprobadas. La primera propuesta más amplia fue rechazada automáticamente; se restauraron los controles adicionales y el despliegue acotado fue autorizado.
